SQL syntax

SQLite implements most of standard SQL, plus a handful of its own extensions. This page groups the statements you'll use most by what they do, each with a minimal example.

Defining structure

CREATE TABLE

CREATE TABLE users (
  id INTEGER PRIMARY KEY,
  name TEXT NOT NULL,
  email TEXT UNIQUE
);

CREATE INDEX

CREATE INDEX idx_users_email ON users (email);

ALTER TABLE / DROP TABLE

ALTER TABLE users ADD COLUMN created_at TEXT;
DROP TABLE users;

Reading and writing rows

SELECT

SELECT id, name FROM users
WHERE email LIKE '%@example.com'
ORDER BY name
LIMIT 20;

INSERT

INSERT INTO users (name, email)
VALUES ('Ada', 'ada@example.com');

UPDATE / DELETE

UPDATE users SET name = 'Ada Lovelace' WHERE id = 1;
DELETE FROM users WHERE id = 1;

Transactions

Wrap related statements in a transaction so they succeed or fail together: 

BEGIN;
UPDATE accounts SET balance = balance - 100 WHERE id = 1;
UPDATE accounts SET balance = balance + 100 WHERE id = 2;
COMMIT;

SQLite-specific extensions

Upsert (INSERT ... ON CONFLICT)

Insert a row, or update it if it already exists:

INSERT INTO users (id, name) VALUES (1, 'Ada')
ON CONFLICT (id) DO UPDATE SET name = excluded.name;

RETURNING

Get the row back from an insert, update, or delete:

INSERT INTO users (name) VALUES ('Grace')
RETURNING id, name;

JSON functions

Query and shape JSON stored in a text column:

SELECT json_extract(profile, '$.city') FROM users
WHERE json_extract(profile, '$.active') = 1;
