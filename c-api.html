C/C++ API

SQLite is a C library first — every other language binding calls through to this API. Most programs only ever need the five functions below.

The core workflow

Every query follows the same five steps:

sqlite3 *db;
sqlite3_open("hello.db", &db);

sqlite3_stmt *stmt;
sqlite3_prepare_v2(db, "SELECT id, name FROM users WHERE id = ?", -1, &stmt, NULL);
sqlite3_bind_int(stmt, 1, 1);

while (sqlite3_step(stmt) == SQLITE_ROW) {
  int id = sqlite3_column_int(stmt, 0);
  const unsigned char *name = sqlite3_column_text(stmt, 1);
}

sqlite3_finalize(stmt);
sqlite3_close(db);
  • sqlite3_open — opens (or creates) the database file.
  • sqlite3_prepare_v2 — compiles a SQL string into a reusable statement.
  • sqlite3_bind_* — fills in ? placeholders safely, with no string concatenation.
  • sqlite3_step — runs the statement, one row at a time.
  • sqlite3_finalize / sqlite3_close — release the statement and the database handle.

The convenience shortcut: sqlite3_exec

For a statement with no parameters and no rows to read back, skip straight to a callback: 

sqlite3_exec(db, "CREATE TABLE users (id INTEGER PRIMARY KEY, name TEXT)",
             NULL, NULL, NULL);

Checking for errors

Every function returns an integer result code. Anything other than SQLITE_OK (or SQLITE_ROW / SQLITE_DONE from sqlite3_step) is worth checking: 

int rc = sqlite3_open("hello.db", &db);
if (rc != SQLITE_OK) {
  fprintf(stderr, "open failed: %s\n", sqlite3_errmsg(db));
}

Full example

#include <sqlite3.h>
#include <stdio.h>

int main(void) {
  sqlite3 *db;
  sqlite3_stmt *stmt;

  if (sqlite3_open("hello.db", &db) != SQLITE_OK) {
    fprintf(stderr, "open failed: %s\n", sqlite3_errmsg(db));
    return 1;
  }

  sqlite3_exec(db,
    "CREATE TABLE IF NOT EXISTS notes (id INTEGER PRIMARY KEY, body TEXT)",
    NULL, NULL, NULL);

  sqlite3_prepare_v2(db, "INSERT INTO notes (body) VALUES (?)", -1, &stmt, NULL);
  sqlite3_bind_text(stmt, 1, "hello from C", -1, SQLITE_STATIC);
  sqlite3_step(stmt);
  sqlite3_finalize(stmt);

  sqlite3_close(db);
  return 0;
}
