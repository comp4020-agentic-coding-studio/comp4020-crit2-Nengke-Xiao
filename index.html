The database engine already running on your phone

SQLite is a small, fast, self-contained SQL database engine with no server to install and no configuration to get wrong. It's embedded in more devices and applications than any other database, from web browsers to operating systems to the app you used this morning.

Why teams reach for SQLite

  • Self-contained

    One library, no external dependencies, no server process to manage. Your whole database is a single file.

  • Zero-configuration

    There's no setup wizard because there's nothing to set up. Link the library and start reading and writing SQL.

  • Cross-platform

    The same database file works unmodified across Windows, macOS, Linux, iOS, Android, and everything in between.

  • ACID-compliant

    Transactions are atomic, consistent, isolated, and durable — even if the power fails mid-write.

  • Public domain

    No licence to negotiate and no attribution required. Use it in anything, commercial or not.

  • Deployed at scale

    Billions of copies are in active use in browsers, operating systems, and applications worldwide.
