Download SQLite

There isn't one "download SQLite" button — the right file depends on how you plan to use it. This page helps you pick, then hands off to the current files and checksums on the official download page.

Precompiled binaries

For Windows, macOS, and Linux, precompiled binaries of the sqlite3 command-line shell and the core library are rebuilt for every release. Grab the one matching your platform and CPU architecture from the official download page, which always lists the current release.

A package manager is usually easier

If you just want the CLI shell to try things out, your system's package manager already has it: 

# macOS (Homebrew)
brew install sqlite

# Debian / Ubuntu
sudo apt install sqlite3

# Fedora
sudo dnf install sqlite

See Get Started for what to do once it's installed.

Source code

SQLite's source is public domain and available as a single "amalgamation" — the entire engine flattened into one C file — so embedding it doesn't require a build system of its own. The amalgamation and the full source tree are both on the official download page.

Verifying a download

Every release publishes a SHA3-256 checksum alongside the file. Compare it after downloading: 

shasum -a 256 sqlite-tools-linux-x64.zip

Match the output against the checksum listed next to the file on the download page before you trust it.
