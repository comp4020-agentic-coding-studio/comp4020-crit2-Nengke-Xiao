Guides

These summarise concepts worth understanding before you rely on SQLite in production; each links to the full, authoritative write-up.

  • Data types

    SQLite uses dynamic typing: a column's declared type is a hint, not a constraint, and most values are stored using whichever of five storage classes fits them best. Read the full guide (opens in a new tab).

  • File format

    Every database is a single cross-platform file with a documented, stable binary layout — which is also why SQLite is a common choice for long-term archival. Read the full guide (opens in a new tab).

  • Transactions & concurrency

    Transactions are ACID by default, and write-ahead logging mode lets readers keep working while a write is in progress. Read the full guide (opens in a new tab).

  • Extending SQLite

    Loadable extensions and user-defined functions let you add behaviour — full-text search, geospatial queries, custom collations — without forking the engine. Read the full guide (opens in a new tab).
