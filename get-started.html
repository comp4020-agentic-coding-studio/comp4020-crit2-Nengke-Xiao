Get started with SQLite

Five minutes from nothing installed to your first query. No server to set up first.

1. Install the command-line shell

The sqlite3 shell is the fastest way to try SQLite without writing any code. It's already packaged for most systems: 

# macOS (Homebrew)
brew install sqlite

# Debian / Ubuntu
sudo apt install sqlite3

# Windows and everything else
# grab the precompiled binary from the download page

Prefer to install by hand? Precompiled binaries for every platform are on the Download page.

2. Create your first database

A SQLite database is just a file. Opening a file that doesn't exist yet creates it: 

sqlite3 hello.db

sqlite> CREATE TABLE notes (id INTEGER PRIMARY KEY, body TEXT);
sqlite> INSERT INTO notes (body) VALUES ('SQLite works with no setup');
sqlite> SELECT * FROM notes;
1|SQLite works with no setup

That's it — hello.db is a complete, portable database you can copy, back up, or ship inside an application.

3. Use it from your language

Most languages either bundle a SQLite driver or have a well-maintained one a package manager away:

  • Python — sqlite3 ships in the standard library; no install needed.
  • Node.js — the built-in node:sqlite module, or better-sqlite3 for older runtimes.
  • C / C++ — link against the engine directly with the C/C++ API.
  • Everything else — check your language's package index; SQLite bindings exist for nearly all of them.
